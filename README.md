# Красный фонарь — Касса

Интерфейс рабочего места кассира ресторана быстрого обслуживания «Красный фонарь» (ЛР 1–3 по ПЧМИ).

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `app/` | Сама программа (Node.js + Vite + React + Mantine) |
| `winhelp/` | Справка для ЛР3: `KRASNY.RTF`, `KRASNY.HPJ`, `KRASNY.CNT`, картинки в `IMG/` |
| `shots/` | Скриншоты и схемы (используются в отчётах) |
| `tools/` | Скрипты, которые пересобирают скриншоты, справку и отчёты |

## Запуск программы

Двойной щелчок по `start.bat` или:

```bash
cd app
npm install
npm run dev
```

Откройте http://localhost:5173. Полезные клавиши: Insert — новый заказ, F2/F3/F4/F6 — журнал/меню/гости/кухня,
F9 — оплата, Ctrl+Enter — выбрать, Esc — назад, F1 — справка, Alt — меню.
Переключатель «Номера операций в меню» в правом нижнем углу показывает номера операций из ЛР1 прямо в меню.

## Перед сдачей

1. Заполните титульные листы: в файле `tools/reports/common.mjs` блок `TITLE` (университет, ФИО, группа, преподаватель)
   и пересоберите отчёты командой `node tools/reports/build.mjs` из папки проекта, либо исправьте титульники прямо в Word.
2. ЛР3: скомпилируйте справку. Откройте `winhelp/KRASNY.HPJ` в Microsoft Help Workshop (hcw.exe) → **Save and Compile** →
   **File | Run WinHelp**. Получится `KRASNY.HLP`. Для просмотра .hlp в Windows 10/11 нужна программа WinHlp32.

## Пересборка материалов

При запущенной программе (`npm run dev`):

```bash
node tools/shots.mjs            # скриншоты экранов и меню
node tools/diagrams.mjs         # схема навигации, граф состояний, карта справки
node tools/build-winhelp.mjs    # RTF/HPJ/CNT из app/src/help.js
node tools/make-bmp.mjs         # картинки BMP для справки
node tools/reports/build.mjs    # три отчёта .docx
```

Операции, состояния меню и переходы описаны в одном файле `app/src/spec.js`, темы справки — в `app/src/help.js`;
программа, схемы и отчёты берут данные оттуда, поэтому номера везде совпадают.
